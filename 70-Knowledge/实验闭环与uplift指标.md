# 实验闭环与 uplift 指标

## 是什么（自己的话，≤3 句）
评测知识库价值的标准做法：同一 agent 分「无指南/有指南」两组跑同一批任务，`opportunity = 100% − 无指南通过率`（改进空间），`uplift = 有指南 − 无指南`（实际增益）。考卷须先校准：黄金解 100% 通过、未修改基线 100% 失败；任务提示词不点名答案（测发现能力，不测背诵），评分用确定性断言而非 LLM 裁判。

## 为什么重要 / 什么时候用
- 评估任何"给 AI 补知识"的方案（RAG、Skill、prompt 注入）是否真有效时；
- uplift≈0 剪内容、agent 持续失败就打磨内容——评测结果直接驱动内容治理。
