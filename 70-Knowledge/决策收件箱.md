# 决策收件箱（Decision Inbox）

## 是什么（自己的话，≤3 句）
Agent 驱动的工作流推进到人工中断点时，把"事项 + 证据 + AI 推荐（含依据与置信度）+ 反方证据 + 操作"打包成一个决策包，送到人的默认工作界面等人表态。人的界面从"任务清单"（我该做哪件事）翻转为"决策收件箱"（哪些进程在等我表态）。

## 为什么重要 / 什么时候用
- 人机分工定型为：Agent 执行与串接、人决策与补充信息——人的效率取决于决策包质量而非任务数量；
- 三护栏：推荐可解释可追责、反方证据必须呈现（禁止诱导）、否决与复核留痕且推荐人≠决策人；
- 自动化程度分级演进（人批准 → 低风险白名单自动+上线观察 → 大范围自动），每级可回退，自动化范围本身是被治理的版本化标准。
