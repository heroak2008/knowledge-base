# 技能自进化（Skill as Trainable State）

## 是什么（自己的话，≤3 句）
把 Agent 的 skill 文档当作"外部权重"：冻结目标模型，由 optimizer 模型复盘任务轨迹，对文档做**有界编辑**（~4 处/轮），改动必须在 held-out 验证集上严格提升才保留、否则回滚进失败档案——像训练神经网络一样训练 skill，但零权重更新、部署零额外推理调用。

## 为什么重要 / 什么时候用
- 手写 skill 是试错手工活（无 loss、无验证集、无收敛保证）；自进化把它变成系统化训练；
- 部署物是 300–2000 token 的 `best_skill.md`——训练结果天然是"薄入口"；
- 夜间 Sleep 模式（harvest→mine→replay→consolidate）可持续从历史轨迹进化。
