# 薄入口厚语料（Thin Router, Fat Corpus）

## 是什么（自己的话，≤3 句）
Agent 外挂知识库的入口层（路由规则 + 消费协议）压到 ~200 tokens 常驻，全部知识正文放检索层按需载入；上下文按"路由 → 索引(id+描述) → 正文全文"三级漏斗逐级放大，不相关内容永不进上下文。

## 为什么重要 / 什么时候用
- Agent 上下文昂贵且有限，常驻的只能有「何时触发」（正负清单）与「怎么消费」（协议）；
- 设计 RAG / Skill 系统时控制每一层的进入条件与放弃条件（重试→list→放弃），防 Agent 空转。
