# 任务续作与现场隔离

## 是什么（自己的话，≤3 句）
长期知识与短期任务现场必须分层：系统"应该怎样"入中心知识目录（system-design / SPEC / ADR），某次执行"做到哪里"记在任务级的 `resume.md`（目标、已验证事实、代码现场、未决项、下一步）。不建议所有 Agent 共编一份全局 `state.md`——多任务/多成员并行会互相覆盖。

## 为什么重要 / 什么时候用
- Agent 中断恢复：读取顺序 = 入口(AGENTS.md) → resume.md → 核对授权/修订/代码 → 增量事件 → 继续执行；
- resume 是"薄入口"：少量事实 + 精确导航，原始日志/diff 靠引用按需读取，不复制进摘要；
- 恢复的是**工作上下文**，不承诺恢复模型隐藏状态；外部副作用先按 operation/job ID 查证再续作，不盲目重提。
