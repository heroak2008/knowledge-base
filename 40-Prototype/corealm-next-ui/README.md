## 功能要点（摘自 usage-guide）

1. **产品主空间切换**：以产品划分主空间，切换=换上下文，平台能力（资产/治理/运行时/经验/通知）不随切换消失
2. **我的工作**：按"下一动作归谁"组织，七分组 + 今日焦点(≤5条) + 同类合并行 + 空间 facet 筛选（挂起等答置顶不受筛选影响）；**决策收件箱（v1.17）**——Agent 申请带证据/可解释推荐/反方证据，人批准·否决·补充信息·亲自看（L2 演进起点）
3. **任务作业台**：四维状态带 + 下一步芯片 + 五页签
4. **执行 Trace**：空态引导 → 实时进度 → 完成后事件按类型着色的时间线 + 详情面板
5. **治理中心**：三道门·一门一裁决人，例外备案≠通过，裁决理由必填；受辖对象显式化（v1.17）——资产发布/知识固化/改进发布回退统一裁决队列，管理面与裁决面分离
6. **经验中心**：候选→评审→发布→引用（对应知识工程治理流）
7. **用量统计（v1.17）**：三来源 Token/Credit 归集去重 + 公司侧核对 + 任务/资产归因；只统计不做准入
8. **持续改进（v1.17）**：并入"运营与进化"页的三个子页签——改进候选流 + 上线观察（可回退）+ 评测数据集（调优/验证隔离）；用量统计保持独立页（对账账本）
9. **快捷键**：`/` 全局搜索，`Esc` 分层关闭，`←→` 页签切换，中文输入法安全
