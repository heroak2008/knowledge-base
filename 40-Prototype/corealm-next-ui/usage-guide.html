15用量统计（M14 · v1.17 增补）

侧栏"平台能力"组新增 用量统计 页，对应设计方案 v1.17 的 M14 模块。三个页签：

  • 来源明细：执行端 / 产业网关 / 公司侧三来源的 Token/Credit 记录；同一次调用多来源按执行回执去重，各来源保留原始值；失败重试也如实入账。
  • 公司侧核对：口径差异、迟到修订、重复归集逐笔处理，修订保留原值，责任人与状态可见。
  • 任务与资产汇总：用量归因到任务与资产版本，附计量口径说明。

边界提示：平台只统计与核对，不做金额、预算、额度准入与支付——额度不足由供给侧返回失败，平台记录并展示。

16持续改进子页签（M13/M16 · v1.17 增补）

"运营与进化"页在原有三个页签（系统接入/执行观测/平台运维）基础上新增三个子页签，对应 M13 持续改进管理与 M16 评测数据集：

  • 改进候选流：来源（运营分析/执行记录/人工提出）→ 假设 → 立项 → 评测中 → 上线观察；不经过评测验证不发布，发布走治理中心三道门。
  • 上线观察：发布后按观察指标对照，不达标可发起回退（回退需治理中心登记裁决理由，回退后回到候选并保留观察记录）。
  • 评测数据集：样本按授权导入并脱敏标注；调优集与验证集严格隔离；冻结版本不可变；撤回需追踪影响的历史评测版本。

首批改进用现有 Issue/Task 跟踪即可，本页呈现的是目标闭环形态。
